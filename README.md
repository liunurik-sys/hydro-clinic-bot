# Telegram-бот клиники — деплой на Render (бесплатно, без Replit)

Это рабочий Telegram-бот для клиники (@Colonotaraphy_bot), написанный заново на
aiogram 3, не зависящий от Replit. Использует тот же токен бота и того же
администратора, что были настроены в Replit — просто переносим бота на бесплатный
хостинг, который умеет работать 24/7.

Что умеет бот из коробки:
- приветствие и главное меню;
- «Услуги и цены», «Адрес и часы работы», «Частые вопросы» — тексты-заглушки,
  замените на реальные (см. блок `CONFIG` в самом начале `bot.py`);
- «Записаться на консультацию» — бот спрашивает имя, телефон и удобное время,
  затем сразу пересылает заявку администратору в Telegram.

Хранения данных в базе нет и не нужно (бесплатные хостинги стирают диск при
«засыпании», так что заявки надёжнее пересылать сразу в Telegram, что бот и
делает).

---

## Шаг 1. Заполните реальные данные клиники (по желанию, можно и позже)

Откройте `bot.py`, в самом верху — блок `CONFIG` с текстами `ADDRESS_TEXT`,
`SERVICES_TEXT`, `FAQ_TEXT`. Замените плейсхолдеры в квадратных скобках на
реальные адрес, часы работы, цены и т.д. Можно пропустить этот шаг и
отредактировать прямо на GitHub позже.

## Шаг 2. Выложите код на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно, карта не
   нужна), если аккаунта ещё нет.
2. Нажмите **New repository**, назовите, например, `hydro-clinic-bot`,
   оставьте приватным ли публичным — не важно, нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** (или
   «Add file → Upload files») и перетащите туда все файлы из этой папки:
   `bot.py`, `requirements.txt`, `Procfile`, `.gitignore`, `README.md`.
4. Нажмите **Commit changes**.

## Шаг 3. Разверните на Render

1. Зарегистрируйтесь на [render.com](https://render.com) (бесплатный план,
   обычно без привязки карты — проверьте это при регистрации).
2. Нажмите **New +** → **Web Service**.
3. Подключите свой GitHub-аккаунт и выберите репозиторий `hydro-clinic-bot`.
4. Настройки:
   - **Name**: любое, например `hydro-clinic-bot`
   - **Region**: любой ближайший
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
   - **Instance Type**: **Free**
5. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN` = токен бота (тот же, что лежит в Replit в Secrets под именем
     `CLINIC_BOT_TOKEN` — откройте его там и скопируйте значение)
   - `ADMIN_CHAT_ID` = `1119005938`
6. Нажмите **Create Web Service**. Render соберёт и запустит бота — это
   занимает пару минут. Следите за логами: должна появиться строка
   `Starting long polling…` без ошибок.
7. Откройте бота в Telegram (@Colonotaraphy_bot) и отправьте `/start` —
   должно появиться приветствие и меню.

## Шаг 4 (рекомендуется). Не давайте боту «засыпать»

Бесплатный план Render «усыпляет» сервис после 15 минут без обращений и
«будит» его при следующем запросе (это занимает ~30–60 секунд). Чтобы бот
отвечал мгновенно в любое время, настройте бесплатный пинг:

1. Зарегистрируйтесь на [cron-job.org](https://cron-job.org) (бесплатно).
2. Создайте задачу, которая каждые 5–10 минут делает GET-запрос на адрес
   вашего сервиса на Render (он вида
   `https://hydro-clinic-bot-XXXX.onrender.com/` — Render покажет точный
   адрес на странице сервиса).

Без этого шага бот всё равно будет работать 24/7, просто первое сообщение
после долгой паузы может прийти с задержкой в полминуты.

## Дальнейшие изменения

Чтобы поменять тексты (цены, адрес, FAQ) или доработать логику — правьте
`bot.py` прямо на GitHub (кнопка карандаша на странице файла) и сохраняйте
(**Commit changes**). Render автоматически пересоберёт и перезапустит бота
при каждом изменении в репозитории.
